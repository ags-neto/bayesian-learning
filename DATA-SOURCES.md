# Fontes de dados externas

## `forestfire.txt` — UCI Forest Fires

- **O que é:** 517 registos de incêndios florestais no Parque Natural de Montesinho
  (Bragança, Portugal), com 13 variáveis meteorológicas e o resultado (área ardida).
- **Autoria:** Paulo Cortez e Aníbal Morais (2007).
- **Onde:** UCI Machine Learning Repository — <https://doi.org/10.24432/C5D88D>
  (dataset *Forest Fires*).
- **Licença:** **CC BY 4.0** (<https://creativecommons.org/licenses/by/4.0/>) — uso e
  redistribuição permitidos **com atribuição**, que é o que este ficheiro faz.
- **Formato aqui:** `forestfire.txt` é uma cópia do `forestfires.csv` do UCI separada por
  espaços, com uma coluna extra de número de linha. Os valores não foram alterados.

Ao reutilizar este ficheiro, mantém esta atribuição.
